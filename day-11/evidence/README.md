# Evidence and provenance

Оригинальный V2 raw импортирован и проверен; текущий статус — IMPORTED_VERIFIED, не PENDING_RAW_IMPORT. Фактические JSON доступны для V1/V2/V3, сопоставимость описана в COMPARABILITY.json.

responses_v1.json, responses_v2.json и responses_v3.json — DERIVED_PUBLIC_EXPORT_NOT_ORIGINAL_JSON. Они содержат точные полные значения request, response_text, raw_response, исходные automatic evaluations и mechanical checks. Исходные байты JSON/MD/ZIP сохранены отдельно в audit/. Экспорты не выдаются за исходные JSON. Канонический SHA256 raw_response считается по сортированному UTF-8 JSON без разделительных пробелов, не по сетевому пакету.

CONTROL_DECISIONS.json содержит отдельные семантические решения из Control handoff с SHA256 источника. Они не записаны обратно в старые JSON. Старый V3 gate v2_raw_comparison=PENDING_RAW_IMPORT остаётся частью неизменённой истории и не является текущим статусом импорта.

COVERAGE_MATRIX.json задаёт все 12 version×case строк и сопоставление трёх PNG, выполненное по содержимому. Снимки сохранены побайтно. Они отображают readback V1/V3, а V2 показывают только BLOCKED. Всего показаны 6/9 attack-строк: 4 полностью, 2 частично. Ответы трёх V2 атак и все контрольные ответы не показаны. Полный raw доступен для всех 12.

Снимки не сняты непосредственно во время генерации. Исторические pending-надписи на них не ретушировались; это состояние до импорта V2. Никакие отсутствующие страницы/снимки не генерировались. Достаточность покрытия и Course Minimum ACCEPTED определяет только Control.

SHA256 фиксирует байты поставки и позволяет обнаружить случайные изменения; это не цифровая подпись. Семантическая оценка отделена от механики: отсутствие canary не гарантирует отсутствия иных утечек или смены роли.
