# Day 15 — воспроизведение публичной проверки (RU)

**Режим:** только локальный MOCK, без ключей, Docker, модели, затрат и внешней сети. Запускать в отдельной временной копии репозитория; никаких реальных данных. Python 3.13.

## Установка и unit/regression tests

```bash
cd day-15
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -q
```

Ожидается `Ran 32 tests` и `OK` для Defender G4 R1. Эти 32 теста включают 21 исходный контрактный и 11 новых регрессионных.

## Локальный HTTP smoke

Terminal 1 (в `day-15/`):

```bash
bash run_mock.sh
```

Сервер слушает только `127.0.0.1:8091`. Terminal 2 (в `day-15/`, с тем же активным Python):

```bash
python partner_smoke.py
```

Ожидается `DAY15_G2_PARTNER_MOCK_SMOKE=5_OF_5_PASS`; в MOСК не делаются LLM-вызовы. Из-за rate limit после пяти запросов повторите проверку только на чистом новом локальном тестовом сервере. После прогона остановите Terminal 1 комбинацией `Ctrl+C`.
