# UI-01 — Create Task

Version: 1.0.0

Prerequisites: реальный Firefox через Playwright MCP; Day 3 app доступен на localhost:8003; без ручных действий.

1. Открыть http://127.0.0.1:8003/ui. Проверить поле Task title, кнопку Create и пустой список Tasks. Сохранить PNG `evidence/screenshots/UI-01/step-01.png` реальным browser_take_screenshot и записать assertion.
2. Ввести UI-01 Bublik task через browser_type. Проверить значение поля. Сохранить PNG `evidence/screenshots/UI-01/step-02.png` реальным browser_take_screenshot и записать assertion.
3. Нажать Create через browser_click. Дождаться строки задачи; проверить title=UI-01 Bublik task, status=todo, ровно одна строка. Сохранить PNG `evidence/screenshots/UI-01/step-03.png` реальным browser_take_screenshot и записать assertion.

При ошибке: сохранить MCP error, состояние страницы и screenshot, если браузер доступен. При инфраструктурном BLOCKED не подделывать PNG и не выполнять сценарий через HTTP. Не менять данные DOM или ответы сервера через evaluate.
