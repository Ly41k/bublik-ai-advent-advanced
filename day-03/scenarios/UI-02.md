# UI-02 — Update Task

Version: 1.0.0

Prerequisites: реальный Firefox через Playwright MCP; Day 3 app доступен на localhost:8003; без ручных действий.

1. Открыть /ui. Проверить пустой список отображаемых задач. Сохранить PNG `evidence/screenshots/UI-02/step-01.png` реальным browser_take_screenshot и записать assertion.
2. Ввести UI-02 Bublik task через browser_type. Проверить значение поля. Сохранить PNG `evidence/screenshots/UI-02/step-02.png` реальным browser_take_screenshot и записать assertion.
3. Нажать Create через browser_click. Дождаться новой задачи со status=todo. Сохранить PNG `evidence/screenshots/UI-02/step-03.png` реальным browser_take_screenshot и записать assertion.
4. Нажать Mark done через browser_click. Дождаться status=done у той же строки; проверить неизменные title/task-id и disabled Mark done. Сохранить PNG `evidence/screenshots/UI-02/step-04.png` реальным browser_take_screenshot и записать assertion.

При ошибке: сохранить MCP error, состояние страницы и screenshot, если браузер доступен. При инфраструктурном BLOCKED не подделывать PNG и не выполнять сценарий через HTTP. Не менять данные DOM или ответы сервера через evaluate.
