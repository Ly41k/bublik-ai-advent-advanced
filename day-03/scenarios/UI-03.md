# UI-03 — Validation

Version: 1.0.0

Prerequisites: реальный Firefox через Playwright MCP; Day 3 app доступен на localhost:8003; без ручных действий.

1. Открыть /ui. Проверить пустое поле Task title и ноль строк Tasks. Сохранить PNG `evidence/screenshots/UI-03/step-01.png` реальным browser_take_screenshot и записать assertion.
2. Нажать Create, оставив поле пустым. Проверить видимую ошибку Task title must contain 1–200 characters. и ноль строк задач. Проверить browser_network_requests: POST /tasks вернул 422. Сохранить PNG `evidence/screenshots/UI-03/step-02.png` реальным browser_take_screenshot и записать assertion.

При ошибке: сохранить MCP error, состояние страницы и screenshot, если браузер доступен. При инфраструктурном BLOCKED не подделывать PNG и не выполнять сценарий через HTTP. Не менять данные DOM или ответы сервера через evaluate.

Граница проверки: отсутствие создания подтверждается UI (0 строк) + HTTP 422, наблюдаемым через browser_network_requests; API списка задач не добавляется.
