# Day 13 · LLM Gateway

Course Minimum. FastAPI принимает текст, применяет входной guard, вызывает выбранный сервером провайдер, проверяет полный ответ и пишет JSONL-аудит. По умолчанию используется детерминированный Mock Provider. Результаты G1 относятся к Linux и синтетическим данным.

## Воспроизведение офлайн

Распакуйте ZIP и перейдите в каталог day-13. Установка зависимостей требует локального кэша или доступа к индексу пакетов. После установки тестам сеть не нужна. Скрипт smoke использует ASGI TestClient внутри процесса.

~~~sh
cd day-13
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-test.txt
unset OPENAI_API_KEY
export GATEWAY_PROVIDER=mock LIVE_ENABLED=false
python -m pytest -q
python -m tests.smoke
~~~

Ожидаемый smoke — clean 200, blocked 403, masked 200, rate_limited 429, origin MOCK. Для отдельного воспроизводимого фрагмента аудита используйте python -m tests.smoke ./audit-replay.jsonl. Скрипт пишет только четыре строки метаданных из своего временного синтетического прогона.

## Локальный запуск

~~~sh
unset OPENAI_API_KEY
export GATEWAY_PROVIDER=mock LIVE_ENABLED=false
export GATEWAY_AUDIT_PATH=./audit.jsonl
umask 077
python -m uvicorn gateway.app:app --host 127.0.0.1 --port 8013 --workers 1 \
  --no-proxy-headers --no-access-log --log-level warning
~~~

В другом терминале:

~~~sh
curl -fsS http://127.0.0.1:8013/health
curl -fsS http://127.0.0.1:8013/v1/chat \
  -H 'Content-Type: application/json' \
  --data '{"prompt":"Коротко объясни HTTP","mode":"block"}'
~~~

GET /health возвращает версию политики и состояние live-режима. POST /v1/chat принимает application/json с полем prompt и опциональным mode. Значение по умолчанию — block. Лимиты — 4096 символов Unicode и 16 КиБ JSON-тела. Любые дополнительные поля запрещены.

| HTTP | Условие |
|---|---|
| 200 | Прошли обе проверки, метаданные записаны в аудит |
| 403 | Сработал входной или выходной guard |
| 413 / 422 | Превышен лимит тела или запрос не прошёл валидацию |
| 429 | Исчерпано окно запросов для IP |
| 502 | Ошибка или неприемлемый результат провайдера |
| 503 | Провайдер отключён, пилот остановлен или аудит недоступен |

## Политика и ограничения

- Скользящее окно пропускает пять попыток за 60 секунд на IP TCP-соединения. Валидация тела выполняется первой, затем попытка учитывается даже при 422, 413 или 403. При заполненном окне возвращается 429. Отклонённые 429 попытки не продлевают окно. Заголовок X-Forwarded-For игнорируется приложением. Флаг --no-proxy-headers сохраняет IP сокета в Uvicorn.
- Block останавливает запрос до создания провайдера. Mask заменяет совпадения и проверяет результат повторно. Для перекрывающихся совпадений закрывается весь объединённый диапазон, метку определяет самое длинное совпадение.
- Base64 проверяется в пределах 16–2048 символов и декодируется на один уровень. Поддерживаются стандартный и URL-safe алфавиты и канонический вариант без padding. Декодированный текст проверяется на шаблоны ключей. Обработка разбиения ограничена простыми цепочками строк в кавычках. Вложенные кодировки, экранированные фрагменты и семантические утечки за пределами правил.
- Выходной guard проверяет секреты, точный canary из GATEWAY_SYSTEM_CANARY, системную инструкцию, типовые заголовки её раскрытия, распространённые формы URL и опасные команды. Allowlist внешних URL пуст. Проверка текстовая и может блокировать полезные ссылки и команды. Произвольные обфускации и все возможные формы URI не покрыты.
- Для каждого POST /v1/chat аудит хранит только типизированные метаданные. IP вне loopback заменяется HMAC с ключом текущего процесса. Файл должен быть обычным и закрытым для группы и остальных пользователей. Сбой записи закрывает выдачу ответа. Если сбой произошёл после обращения к провайдеру, расход возможен, а запись о нём может отсутствовать.
- Rate limit, HMAC и бюджет пилота находятся в памяти одного процесса. Перезапуск сбрасывает их. Шлюз предназначен для локального запуска на loopback.

## Границы G1 и бюджет

Адаптер использует фиксированные модель gpt-6-luna и OpenAI Responses API. SDK загружается только на допущенном live-пути. Стандартная обработка, 128 выходных токенов, конечный таймаут, store=false, reasoning.effort=none и ноль автоматических повторов. Инструменты и потоковая выдача выключены. Подключение к OpenAI и применимость тарифа в реальном аккаунте в G1 имеют статус NOT_RUN.

LIVE_ENABLED=false и GATEWAY_PROVIDER=mock оставляются в силе до отдельного разрешения Control. Для утверждённого пилота предусмотрен локальный допуск до трёх попыток в одном процессе, одна попытка в работе одновременно, с резервом по оценке и потолком $0.25. Сбой, блокировка ответа, аномальный или отсутствующий учёт останавливают дальнейшие live-попытки. Счётчик процесса служит для локального учёта пилота. Платёжный лимит задаётся на стороне аккаунта.

Оценка использует замороженную версию gpt-6-luna-standard-text-2026-11-04 из G0. Ставки за миллион токенов — $0.10 за обычный вход, $0.01 за кэшированный вход и $0.50 за выход. Применение скидки требует согласованных cached_input_tokens. При отсутствующей статистике usage и cost_usd равны null, а в аудите стоит UNKNOWN. Для блока до обращения к провайдеру аудит фиксирует нулевую оценку и NOT_CALLED. Mock usage синтетический.

Итоги и источники локальных доказательств перечислены в RESULTS.md. Перечень файлов с SHA256 находится в SHA256SUMS.txt в корне ZIP. Проверка из корня распаковки на macOS — shasum -a 256 -c SHA256SUMS.txt, на Linux — sha256sum -c SHA256SUMS.txt.

## Проверка на macOS и пилот OpenAI

- **G3 · Mock Provider.** На macOS с Python 3.13.3 и OpenAI SDK 2.54.0 прошли 69 тестов, включая все 24 сценария матрицы. OpenAI не вызывался.
- **G4 · OpenAI API.** Владелец подтвердил два успешных вызова модели gpt-6-luna, один с чистым вводом и один после маскирования синтетического ключа. Третий запрос шлюз заблокировал на входе с HTTP 403. Суммарная локальная оценка двух вызовов составила $0.00002520.

В RESULTS.md раздельно приведены результаты G1 на Mock Provider и сводка владельца по G3/G4. Фактический счёт OpenAI независимо не сверялся. Команды воспроизведения выше запускают только Mock Provider.
