`qwen2.5-coder:7b` Q4_K_M. Проверенные параметры Chat: `contextLength=8192`,
`maxTokens=1024`, `temperature=0.1`, `topP=0.9`. Это конфигурация, а не полный trace каждого HTTP-запроса.

## Сохранённые неудачи и атрибуция

Исходный Gate3 Agent FAIL, tool probe FAIL и ранний Chat Apply BLOCKED сохранены.
Первый ответ Gate4 Qwen остался STATIC_FAIL/PARTIAL_CONTENT; оператор доработал регрессионные тесты,
добавил InvalidTaskStatusError и применил нормализацию статуса. Подготовленный RED не выдан
за исходный исторический Day2 RED. Успешный автономный local tool loop не подтверждён: **Native Agent NOT_MET**.

В R3 scratch перед return три ASCII-пробела, перед docstring четыре: IndentationError.
Происхождение расхождения **UNDETERMINED**. Возможная ручная опечатка — гипотеза,
не установленный факт и не доказанный дефект модели. Исторический R1 raw GATE6_BLOCKED,
R2 EVIDENCE_ADDED и R3 FAIL не переписаны и не отменяют принятый частичный результат Gate6.

## Вывод и видео

В этих опытах локальная 7B полезна для узких предложений кода с видимым контекстом.
Человеческая проверка необходима для применения, импортов/DTO, типов, тестов
и интерпретации evidence. Облачный workflow дал больше подтверждённых инструментальных
шагов в рассмотренных сценариях; сравнение скорости/цены на разных условиях некорректно.

Видео: **VIDEO_RECORDED_USER_CONFIRMED**. Файл NOT_RECEIVED, review NOT_RUN;
terminal-only — ожидаемый формат, не проверенное свойство готового файла. Путь, SHA,
длительность и URL неизвестны. Сценарий семи экранов — вспомогательный материал, а не проверка готовой записи.

Подготовлена безопасная отчётная поставка для Control Review. Публикация не разрешена.
