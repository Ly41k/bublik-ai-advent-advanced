# Day 4 R2 — приватность и публикация

**Кандидат санитаризированного report-only пакета. Публикация: NOT_AUTHORIZED.**
Безопасность содержания для review не заменяет sign-off Control.

## Allowlist этого пакета

Разрешены только девять заранее перечисленных Markdown/JSON документов: новый итог,
матрица, атрибуция/хронология, статус видео, privacy, machine ledger, предложенный план,
Control summary и SHA256 manifest. В них — публичное имя Бублик, общие hardware/model
метаданные, проверенные конфигурационные значения, scoped статусы, архивные test counts,
относительные имена evidence и их SHA. Файлов raw архивов и исполняемого кода здесь нет.

Фамилии/имена пользователя, hostname, личные абсолютные пути, auth values и сетевые
идентификаторы не копировались. Source IDs/относительные archive member paths и SHA
оставлены только для привязки фактов. Они не дают публичного доступа к private original.
Ссылку/путь видео не создавали. Пакет не содержит изображений, скриншотов, медиа,
Continue raw Console, network diagnostics, private ZIP, source snapshot, YAML или launcher.

## Что остаётся приватным

| Категория | Правило |
| --- | --- |
| Все перечисленные S1–S8 original/review ZIP | Использовать для независимой проверки; не вкладывать и не публиковать raw автоматически |
| Скриншоты IDE/Network и raw Continue Console | Могут содержать личные пути/видимые окна; в report-only пакете отсутствуют |
| Hostname, username, home paths, shell history | Не переносить в публичные документы или видео |
| Credentials, keys, tokens, private auth | Не искать/читать/публиковать; эта поставка их не требует |
| Interface/route/IP/MAC/proxy diagnostics | Хранить в private evidence, публично только ограниченный вывод о проверке |
| Finished video | Не получено и не проверено; считать ещё не прошедшим privacy review |
| Ранние папки day-04 и промежуточные handoff | Не включать целиком в будущую публикацию; только новый явный allowlist |

## Проверка Work

Новые файлы сформированы из выбранных фактов, не слепой копией исходных отчётов.
Проведены чтение всех девяти выходов, статическая проверка UTF-8, фиксированный allowlist
ZIP members, безопасные пути/no symlinks/duplicates, проверка SHA/bytes, поиск личных
path/hostname/token/IP/MAC шаблонов и содержательная сверка ограничений. Известных
приватных значений не обнаружено. Это проверка перечисленных документов, не аудит
всего Mac, IDE, finished video или скрытой телеметрии. Фактические counts — в summary/JSON.

При выявлении утечки либо несовпадения фактов — STOP, сохранить исходник и вернуть
блокер Control; не публиковать, не менять исторические evidence и не запускать retry.
Решение Control о следующем шаге обязательно. Git/publication permissions сейчас отсутствуют.
